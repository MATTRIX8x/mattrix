Basket Viewer — Quick Manual

Eight synthetic currency baskets as real charts, plus a live dashboard that ranks them by strength and coherence — per day, week, month, year or trading session.
IN CHART VERITAS ⚡

01What it is

The Basket Viewer builds the eight currency baskets #EUR #GBP #AUD #NZD #USD #CAD #CHF #JPY as custom symbols from the 28 major pairs and keeps them updated live. Next to them it draws a dashboard that shows how each currency is moving right now.

It reads prices only — it does not open, modify or close trades.

02Synthetic basket charts

How a basket is built

Each basket is the geometric mean of the currency's seven pairs (exponent 1/7), inverted where the currency is the quote. The symbols are created in Symbol group path (default Custom\FX).

History & live data

On start the history is built from M1 data (Days of M1 history, 30 = light, 90 = full). After that the current bar is written every n seconds.

Works alongside MATTRIX SyntheticCharts. Both tools use the same symbol names. A shared write lock makes sure only one of them writes; if the SyntheticCharts EA is running it takes over, and the Viewer's dashboard keeps working as a pure reader.

03The dashboard

One row per basket, sorted from strongest to weakest by pip sum × coherence ratio for the selected reference period (section 06).

  • Basket button — opens (or focuses) that basket's chart on Chart timeframe when opening, with your Chart template if set
  • Value columns — up to four periods, freely chosen (section 04); green = up, red = down, grey = within ±0.5. A value that rounds to zero shows 0, without a sign
  • Coh(x) — how many of the seven pairs agree on the direction, e.g. 7/7. Green / red = 6 or 7 agree, yellow = mixed, dim red = choppy. The letter shows the reference period
  • Dir — majority direction ▲ / ▼

04Columns & sessions

Column 1 … Column 4 each take one period; OFF slots are skipped, the panel width adapts.

Session columns follow the clock. With Session column order on Chronological (default) the session columns are sorted by the start of the session they show — the most recent one on the right. The table then reads left to right like the trading day: once Tokyo has opened it shows LON* NYC* TYO — yesterday’s London and New York, then today’s Tokyo — instead of putting the fresh Tokyo session in front of them. The order therefore changes during the day; YTD, MTD, WTD and DAY keep their slot. Fixed keeps the order of the column inputs, as before v1.13.

Session highlighting — header and column background show where you are in the trading day:

NYC open, and continues (alone, or it ends last in an overlap)   LON open, ends within the current overlap   TYO not open

The star means "last trading day", not "yesterday". A session column is never empty: if the session has not yet run on the current trading day, it shows the last completed one, marked * (e.g. NYC*). The trading day rolls at 17:00 New York, so after the NY close all three sessions carry a star until Tokyo opens — and on Monday morning NYC* is Friday's session.

05Reading the numbers

  • Pip sum per basket — a basket value is the sum of the pip moves of its seven pairs over the period, each counted in the currency's direction. It is not the move of any single instrument
  • JPY pairs are counted in 0.01 pips, all others in 0.0001 — so every pair contributes on the same pip scale
  • DAY ≠ TYO. The day bar starts at the broker's midnight (with the usual GMT+2/+3 servers: 17:00 New York), Tokyo two hours later. DAY therefore also contains the thin rollover hours before Tokyo
  • DAY ≠ TYO + LON + NYC. Session overlaps count twice in the session columns, and the hours before Tokyo are in none of them

06Reference period & AUTO

Reference period for ranking and coherence drives the sort order, Coh(x), Top Pairs and the snapshot. Choose any of the seven periods, or AUTO.

AUTO ranks by the open session that started first. It switches to a new session only when the previous one has closed — so the ranking never rests on the first few minutes of a fresh session. With no session open it uses the last New York session (NYC*).

The ranking jumps when a session closes. At that moment AUTO changes its reference, and the row order can change in one step. That is intended, not a glitch. During overlaps the highlighted column and the ranking session differ on purpose: the highlight shows what continues, the ranking uses the session with the most data.

07Top Pairs

The three best-scored pairs from all strong/weak combinations: 70 % basket spread + 30 % combined coherence. Click a pair to open its chart.

The value is a basket spread, not the pair's pips. EURAUD SELL (+186) means the AUD basket is 186 pips of sum ahead of the EUR basket — EURAUD itself has not moved 186 pips.

08Snapshot & export

With Show snapshot text on chart enabled, a text block to the right of the dashboard summarises the reference period: strongest and weakest currency, best pair, and a line with the session hours of the current trading day in server time, coloured like the columns:

TYO 02-11   LON 10-19   NYC 15-00

In the weeks when London and New York change their clocks on different dates, these hours shift against each other — the line shows it.

Clicking the top basket also writes two text files to the terminal's MQL5\Files folder: MATTRIX_Snapshot_en.txt (chart and comment text) and MATTRIX_Snapshot_de.txt (short German version for messengers).

09Server time

Session windows are defined in UTC and converted to your broker's server time. The Viewer measures the server offset itself. If your broker follows the common New York close convention (GMT+2 winter / GMT+3 summer), it recognises this and applies the correct offset to past sessions as well, even across a daylight-saving weekend. The journal reports the result on start, e.g. Server time GMT+3.0 (NY-close convention, DST-aware).

Keep your PC clock right. The measurement compares server time with your computer's UTC time. A clock off by a few minutes is tolerated; a wrong time zone setting on the PC is not.

11Notes

  • All 28 major pairs must be available at your broker
  • Attach it to any major pair chart, e.g. EURUSD
  • Tick volume on the basket charts is not meaningful — it does not measure the market. For profile tools on # charts use time-based (TPO) modes
  • Session hours follow the common forex convention (08:00–17:00 local), not the opening hours of the stock exchanges
